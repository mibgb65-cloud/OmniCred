# OmniCred v0.1.0

OmniCred 的第一个公开版本。这是一个基于 Wails、React、Go 和 SQLite 构建的本地桌面账号凭据管理器，数据默认只保存在当前 Windows 用户目录中。

## 主要功能

- 新增、查看、搜索、筛选、编辑和删除账号凭据。
- 从某个平台筛选中新增账号时自动预选该平台，并允许继续修改。
- 密码默认隐藏，支持显示与一键复制。
- 动态管理账号平台，支持新增、重命名和安全删除。
- 平台重命名时同步更新关联账号；有关联账号的平台禁止直接删除。
- 支持带字段标签的账号文本解析。
- 支持 `邮箱----密码----用户名` 格式的单条和多行批量导入。
- 批量数据在确认前只保存在内存草稿中，不会提前写入数据库。
- 根据邮箱创建 GitHub 账号草稿，并从内置英文姓名表生成自然用户名和随机强密码。
- 支持亮色与暗色主题。
- 自定义 Windows 标题栏，支持拖动、最小化、最大化和关闭。
- 凭据列表切换和弹窗交互使用轻量动画，并支持系统“减少动态效果”设置。
- 开发模式使用独立配置目录、数据库、API 端口和单实例标识，不会读写生产版数据。

## 设置与运行状态

- 查看当前版本、运行时长、账号数量、SQLite 状态和本地 API 地址。
- 选择新的 SQLite 数据库存储位置。
- 数据迁移使用一致性复制，旧数据库会保留为备份，重启后切换到新位置。
- 通过 GitHub Releases 检查稳定版本更新。
- 安装版可以从设置页二次确认后启动 Windows 卸载程序。
- 卸载入口通过 Windows UAC 请求管理员权限，修复机器级安装时无法启动卸载程序的问题。

## Windows 发布产物

- `OmniCred.exe`：可直接运行的便携版。
- `OmniCred-amd64-installer.exe`：Windows x64 安装包。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验值。

安装包支持 English 和简体中文语言选择，并允许用户分别选择程序安装目录和数据存储目录。已有数据位置设置不会在重装时被覆盖。

## 本地 API

应用运行时会在以下地址提供本地 REST API：

```text
http://127.0.0.1:8787
```

API 仅监听 `127.0.0.1`，不会暴露到局域网或公网。

## 安全提示

> 当前 v0.1.0 按产品需求以明文形式保存密码。任何能够读取数据库文件或访问本机 API 的程序都可能获取密码。

- 不要把真实数据库文件提交到 GitHub 或同步到不可信位置。
- 建议将数据库保存在受当前 Windows 用户权限保护的目录。
- GitHub 账号用户名是否可用，仍需在 GitHub 注册时确认。
- 建议为 GitHub 账号启用双因素认证。

## 已知限制

- 当前仅提供 Windows amd64 构建。
- 当前不提供自动下载和静默安装更新；设置页会打开 GitHub Release 页面。
- 当前数据库未加密。
- 安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示。

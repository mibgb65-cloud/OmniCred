# OmniCred v0.4.1

本版本为新增账号流程加入一键生成强密码功能，减少手动设计密码的成本，同时复用安全随机数生成逻辑。

## 新增功能

- 新增账号时可在密码字段一键生成 18 位强密码。
- 生成的密码保证包含大写字母、小写字母、数字和特殊字符，并排除容易混淆的字符。
- 生成后自动填入并显示密码，仍可通过原有显示/隐藏按钮控制可见性。
- 编辑已有账号时不显示生成入口，避免误覆盖当前密码。

## 问题修复与可靠性

- 密码生成使用系统安全随机数和无偏拒绝采样，不依赖可预测的伪随机数。
- GitHub 账号草稿与普通新增账号共用同一套强密码生成器，避免规则分叉。
- 补充密码长度、字符类别和新增账号表单交互测试。

## 升级说明

- v0.4.0 正式安装版可直接在应用内下载并安装本版本。
- 可直接覆盖安装；本版本不修改数据库结构和 API，已有账号、身份资料、TOTP 设置及恢复码保持不变。
- 更新前请保存正在编辑的内容。Windows 可能请求一次管理员授权，授权后的安装过程静默完成。

## Windows 发布产物

- `OmniCred.exe`：可直接运行的便携版。
- `OmniCred-amd64-installer.exe`：Windows x64 双语安装包，推荐已有安装版使用。
- `SHA256SUMS.txt`：所有 EXE 发布附件的 SHA-256 校验值。
- `update-manifest.json`：应用内更新所需的版本与安装包校验清单。

## 安全提示与已知限制

# OmniCred v0.1.1

这是 OmniCred 的首个补丁版本，重点完善 Windows 安装、卸载和开发调试体验，并优化新增账号时的平台选择。

## 新增与改进

- Windows 安装器新增独立的数据存储目录选择页，程序安装目录与数据库目录可以分别设置。
- 安装器支持 English 和简体中文的数据目录说明与错误提示。
- 重装时如果检测到已有配置，会明确提示并保留当前数据位置，避免覆盖设置或造成账号数据看似丢失。
- 左侧选中某个平台后点击“新增账号”，表单会自动预选当前平台，同时仍允许用户通过下拉框修改。
- 开发版使用独立的 `%APPDATA%\OmniCred-Dev\` 配置和数据库目录，不会读写生产版数据。
- 开发版 API 调整为 `127.0.0.1:8788`，并使用独立窗口标题和单实例标识，可与生产版同时运行。

## 问题修复

- 修复机器级安装后，从设置页启动卸载程序时报 `The requested operation requires elevation` 的问题。
- 卸载入口现在通过 Windows UAC 请求管理员权限；用户取消授权时 OmniCred 会保持运行并显示错误信息。
- 修复 GitHub Actions 安装 NSIS 后未加入环境路径，导致 Release 可能缺少 Windows 安装包的问题。
- 发布流程现在强制读取 `docs/releases/vMAJOR.MINOR.PATCH.md`，缺少对应说明时停止发布。

## 升级说明

- 可以直接运行 `OmniCred-amd64-installer.exe` 覆盖安装 v0.1.0。
- 已有数据库和数据位置设置默认保留，不需要重新导入账号。
- 如需更换数据位置，请在安装完成后通过 OmniCred“设置 → 数据存储”执行迁移。

## Windows 发布产物

- `OmniCred.exe`：可直接运行的便携版。
- `OmniCred-amd64-installer.exe`：Windows x64 双语安装包。
- `SHA256SUMS.txt`：所有 EXE 发布附件的 SHA-256 校验值。

## 安全提示与已知限制

> 当前版本按产品需求以明文形式保存密码。任何能够读取数据库文件或访问本机 API 的程序都可能获取密码。

- 当前仅提供 Windows amd64 构建。
- 当前数据库未加密，请将其保存在受当前 Windows 用户权限保护的位置。
- 安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示。
- 当前不提供自动下载和静默安装更新；设置页会打开 GitHub Release 页面。

# OmniCred v0.3.0

这是 OmniCred 的功能版本，新增按国家保存身份资料的能力，并继续保留原有账号凭据管理功能。

## 新增功能

- 新增“身份资料”页面，可创建、搜索、查看、复制、编辑和删除身份资料。
- 支持国家/地区、完整姓名、中文或本地语言姓名、名、中间名、姓、性别、出生日期、街道地址、城市、地区/省份、邮编、电话、邮箱和可选密码。
- 菲律宾资料中的中间名提供“通常填写母姓”的提示；其他国家可按证件原文填写。
- 身份资料与账号凭据使用独立数据库表和 API，搜索支持姓名、国家、城市、地区、电话和邮箱。
- 旧数据库会在启动时自动迁移到数据库版本 5，不会覆盖已有账号、TOTP 或恢复码。

## 问题修复

- 补充身份资料表单的日期、邮箱、性别和字段长度校验。
- 增加身份资料 API、SQLite 持久化和前端交互测试。

## 升级说明

- 可以直接运行 `OmniCred-amd64-installer.exe` 覆盖安装 v0.2.1。
- 首次启动新版本时会自动创建 `identity_profiles` 表；现有数据保持不变。

## Windows 发布产物

- `OmniCred.exe`：可直接运行的便携版。
- `OmniCred-amd64-installer.exe`：Windows x64 双语安装包。
- `SHA256SUMS.txt`：所有 EXE 发布附件的 SHA-256 校验值。

## 安全提示与已知限制

> 当前数据库未加密，账号密码、身份资料密码、TOTP 设置密钥和恢复码均以明文保存在本机数据库中。请将数据目录放在仅当前 Windows 用户可访问的位置并妥善备份。

- 当前仅提供 Windows amd64 构建。
- 安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示。
- 当前不提供自动下载和静默安装更新；设置页会打开 GitHub Release 页面。

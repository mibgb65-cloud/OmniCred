# OmniCred v0.4.0

本版本新增 Windows 应用内更新：直接在软件中下载安装包，校验完成后提示更新，点击“重启并更新”即可静默升级并自动重新打开。

## 新增功能

- 设置页支持下载更新，显示下载进度、文件大小和校验状态。
- 下载期间可以继续使用其他页面；完成后显示通知，由用户决定何时重启。
- 支持取消下载、下载失败重试；安装器启动失败或取消管理员授权时，应用保留运行并允许重试。
- 安装器等待旧进程退出后覆盖程序，完成后由原用户权限的辅助进程重新打开应用，保留原启动参数和工作目录。
- 发布附件新增 `update-manifest.json`，记录适配架构、安装器名称、大小、SHA-256 和更新协议版本。

## 问题修复与可靠性

- 下载完成和安装前分别校验 SHA-256；大小不符、文件损坏或校验失败的安装包不会执行。
- 校验与执行期间保持安装包只读锁，限制下载来源、重定向、文件大小和超时，避免误执行其他文件。
- 静默升级保留数据存储位置、数据库和设置；替换失败时尝试恢复旧版程序。
- 补充更新状态交互、文件校验、Windows 进程调用，以及安装器等待退出和失败回滚测试。
- 按职责拆分日期控件和测试数据，使全仓代码满足单文件不超过 400 行的工程规范。

## 升级说明

- **v0.3.2 及更早版本首次升级仍需下载并运行 `OmniCred-amd64-installer.exe`。** 旧客户端没有应用内下载和安装逻辑；安装 v0.4.0 后，后续携带兼容清单的新版可直接在软件内更新。
- 可直接覆盖安装，本版本不修改数据库结构，已有账号、身份资料、TOTP 设置和恢复码保留。
- 更新前请保存正在编辑的内容。Windows 可能请求一次管理员授权，授权后的安装过程静默完成。

## Windows 发布产物

- `OmniCred.exe`：可直接运行的便携版。
- `OmniCred-amd64-installer.exe`：Windows x64 双语安装包，推荐已有安装版使用。
- `SHA256SUMS.txt`：所有 EXE 发布附件的 SHA-256 校验值。
- `update-manifest.json`：应用内更新所需的版本与安装包校验清单。

## 安全提示与已知限制

> 当前数据库未加密，账号密码、身份资料密码、TOTP 设置密钥和恢复码均以明文保存在本机数据库中。请妥善保管和备份数据目录。

- 当前仅发布 Windows amd64 构建；应用内更新仅支持正式安装版，开发版和便携版保留发布页入口。
- 安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示。SHA-256 校验依赖受信任的 GitHub 发布清单，不等同于独立发布者数字签名。
- 暂不支持断点续传；关闭应用后，未安装的下载包会清理，下次需要重新下载。
- 自动化验证覆盖文件替换、失败回滚和原进程等待；不同管理员账户的真实 UAC 授权与完整桌面升级仍需人工验收。
- 断电或强制终止安装器可能中断覆盖安装，不属于自动回滚保证范围；本地数据库和设置独立保留。

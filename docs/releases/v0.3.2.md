# OmniCred v0.3.2

这是 OmniCred 的日期输入修复版本，解决身份资料中出生日期显示语言混杂和年份位数不受限的问题。

## 新增功能

- 出生日期改为应用内统一控制的“年份 / 月 / 日”三段式中文输入控件。
- 月份和日期提供中文选择列表，日期数量会根据月份及闰年自动调整。

## 问题修复

- 修复 Windows WebView 原生日期控件同时显示英文月份占位符和中文日期单位的问题。
- 出生年份现在仅接受数字且最多 4 位，无法再输入 `19977` 这类五位年份。
- 增强出生日期完整性与实际日期校验，并补充年份位数及非闰年二月的回归测试。

## 升级说明

- 可以直接运行 `OmniCred-amd64-installer.exe` 覆盖安装 v0.3.1。
- 本版本不修改数据库结构和 API，已有身份资料与账号数据保持不变。

## Windows 发布产物

- `OmniCred.exe`：可直接运行的便携版。
- `OmniCred-amd64-installer.exe`：Windows x64 双语安装包。
- `SHA256SUMS.txt`：所有 EXE 发布附件的 SHA-256 校验值。

## 安全提示与已知限制

> 当前数据库未加密，账号密码、身份资料密码、TOTP 设置密钥和恢复码均以明文保存在本机数据库中。请将数据目录放在仅当前 Windows 用户可访问的位置并妥善备份。

- 当前仅提供 Windows amd64 构建。
- 安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示。
- 当前不提供自动下载和静默安装更新；设置页会打开 GitHub Release 页面。

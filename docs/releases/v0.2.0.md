# OmniCred v0.2.0

这是 OmniCred 的首次功能版本更新，新增本地 TOTP 二步验证码与恢复码管理，并改进 Windows 覆盖升级体验。

## TOTP 二步验证

- 每个账号可以保存可选的 Base32 TOTP 设置密钥。
- 支持 GitHub 使用的 SHA-1、6 位验证码、30 秒周期配置。
- 账号卡片会实时显示当前验证码、剩余秒数和进度，并支持一键复制。
- 新增轻量的 `GET /api/v1/totp` 接口，只刷新已配置账号的动态验证码。
- 文本导入可以解析 `2FA`、`TOTP`、`两步验证` 等字段标签。

## 恢复码

- 每个账号可以按“一行一个”保存恢复码，最多 100 个，每个最长 256 个字符。
- 保存时会自动去除空行和首尾空格，并拒绝重复恢复码。
- 账号卡片默认只显示恢复码数量；需要时可在独立窗口中查看、逐个复制或全部复制。
- OmniCred 不会自动判断恢复码是否已经使用；使用或重新生成后，请手动更新账号记录。

## Windows 安装与升级

- 覆盖安装时会自动定位已有 OmniCred 的安装目录，同时保留手动修改目录的能力。
- 已安装的 v0.1.x 即使没有记录 `InstallLocation`，新版安装器也会通过现有卸载信息识别原目录。
- 后续安装会写入标准的 Windows `InstallLocation` 卸载项，便于升级和系统管理。
- 已有数据库与数据存储位置保持不变，可以直接从 v0.1.1 覆盖升级。

## 数据升级

- 数据库架构升级至 v4，自动增加 TOTP 设置密钥和恢复码字段。
- 迁移会保留已有账号、平台和设置，无需重新导入。

## Windows 发布产物

- `OmniCred.exe`：可直接运行的便携版。
- `OmniCred-amd64-installer.exe`：Windows x64 双语安装包。
- `SHA256SUMS.txt`：所有 EXE 发布附件的 SHA-256 校验值。

## 安全提示与已知限制

> 当前数据库未加密，密码、TOTP 设置密钥和恢复码均以明文保存在本机数据库中。请将数据目录放在仅当前 Windows 用户可访问的位置并妥善备份。

- 当前仅提供 Windows amd64 构建。
- 安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示。
- 当前不提供自动下载和静默安装更新；设置页会打开 GitHub Release 页面。

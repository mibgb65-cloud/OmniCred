# OmniCred v0.2.1

这是 OmniCred 的补丁版本，重点完善账号密码文本批量导入。

## 新增与改进

- 文本导入新增 `账号----密码` 两列格式，用户名可以省略。
- 继续兼容 `账号----密码----用户名` 三列格式和带字段标签的文本。
- 多行两列数据可以先预览，再一次性批量导入；未提供的用户名会保持为空。
- 更新导入区域的格式说明和输入提示。

## 问题修复

- 修复只有一个四横线分隔符时，完整的账号密码行会被识别为无效内容的问题。

## 升级说明

- 可以直接运行 `OmniCred-amd64-installer.exe` 覆盖安装 v0.2.0。
- 本次更新不修改数据库结构，已有账号、TOTP 设置、恢复码和数据存储位置都会保留。

## Windows 发布产物

- `OmniCred.exe`：可直接运行的便携版。
- `OmniCred-amd64-installer.exe`：Windows x64 双语安装包。
- `SHA256SUMS.txt`：所有 EXE 发布附件的 SHA-256 校验值。

## 安全提示与已知限制

> 当前数据库未加密，密码、TOTP 设置密钥和恢复码均以明文保存在本机数据库中。请将数据目录放在仅当前 Windows 用户可访问的位置并妥善备份。

- 当前仅提供 Windows amd64 构建。
- 安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示。
- 当前不提供自动下载和静默安装更新；设置页会打开 GitHub Release 页面。
